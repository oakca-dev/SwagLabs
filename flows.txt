========================================
How to Run
========================================

Install dependencies (first time only):
    pip install pytest playwright pytest-playwright
    playwright install chromium

Run all UI tests:
    python -m pytest ui/tests/ -v

Run in headed mode (see the browser):
    python -m pytest ui/tests/ -v --headed

Run on Firefox:
    python -m pytest ui/tests/ -v --browser firefox

Run on Safari (WebKit):
    python -m pytest ui/tests/ -v --browser webkit

Run a specific test file:
    python -m pytest ui/tests/test_auth.py -v
    python -m pytest ui/tests/test_cart.py -v
    python -m pytest ui/tests/test_checkout.py -v
    python -m pytest ui/tests/test_inventory.py -v

NOTE: Run UI and API tests separately. See api-tests.txt for API instructions.

========================================
Design Decisions
========================================

- Parametrized login: TC-AUTH-01 runs once per valid user
- Full error message verification: to_have_text() not to_contain_text()
- Price tolerance: pytest.approx with abs=0.01
- Autouse fixtures for login in TestCart, TestInventory, TestCheckout
- Page Object Model: all locators in ui/pages/, no raw selectors in tests
- Test data from JSON: test_data/ui/ui_test_data.json
- Sort options, products, users, errors all externalized
